# Orbitrush

Orbitrush is a one-button neon orbit runner built with Next.js. Hold to latch onto a planet's orbit, release to launch, and time a Perfect Latch to keep the combo alive.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm test
```

## Controls

- Desktop: hold and release `Space`
- Mobile: hold and release anywhere on the game screen

The `DEV` button opens the local tuning panel for speed, combo timing, hit range, and visual helpers.
